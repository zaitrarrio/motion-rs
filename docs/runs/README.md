# Run records

One directory per measurement session on named hardware (card, driver, power
limit), as in fastwan-rs and h3-rs. Nothing in the README claims a speed that
is not recorded here.

- `2026-11-20-authoring-container`: the CPU-only container the port was
  written in (4 vCPU, 15 GB, no GPU; WebGPU through lavapipe). Conformance
  and parity only, no timings worth recording.
